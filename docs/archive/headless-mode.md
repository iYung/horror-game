## Headless Mode Checklist

- [x] Task A — `conf.lua` (new) — Create `conf.lua` in the repo root. Read `arg` for a `--headless` entry; if found, set `t.window = false` and `t.audio.enable = false`. Always set `t.window.title = "NIGHTFALL"`. No other changes.

- [x] Task B — `main.lua` — Add headless detection at the top of the file: loop `arg` for `"--headless"` and set a local boolean. When true, define `love.load` to call `require("busted.runner")({ "--output=utfTerminal", "test/" })` then `love.event.quit(0)`. Wrap the existing `love.load`, `love.update`, `love.draw`, and `love.keypressed` definitions in an `else` branch so the normal game is completely unchanged.

- [x] Task C — `core/lua/sim_input.lua` (new) — Implement `SimInput`, a drop-in replacement for `Input` with identical public interface (`new`, `update`, `is_down`, `pressed`). Instead of reading `love.keyboard.isDown`, `update()` snapshots an internally stored `_inject` table into `_down`/`_pressed` (edge-detect pressed on rising edge), then clears `_inject`. Add `inject(actions)` to set `_inject`. All actions default to false when not injected.

- [x] Task D — `game/entities/player.lua` — Add an optional fourth parameter `input_override` to `Player.new`. Assign `self.input = input_override or Input.new({…})` using the existing key map. No other logic changes; the rest of the file is untouched.

- [x] Task E — `game/simulation.lua` (new) — Implement the `Simulation` class. Depends on Task C (SimInput) and Task D (player input override). `Simulation.new(run_config)` sets up: load map, `CameraShake.new()`, `SimInput.new()`, `Player.new(spawn_gx, spawn_gy, map, sim_input)`, `Monster.new(…)` with monster traits from run_config, `ItemSpawner.spawn(map, budget)`, `Extraction.new(map)`. Set `monster.on_kill` to store `self._outcome = "death"`. Wire extraction outcomes into `self._outcome` inside `step`. No raycaster, Drawer, HUD, or scene_ref imports. Expose: `step(dt, actions)` (inject actions into SimInput, call player:update / monster:update / extraction:update, return state snapshot or nil if finished), `state()` (return current snapshot without stepping), `run_until(pred, opts)` (loop `step` with `opts.dt` default 1/60 until `pred(state)` or `opts.max_seconds` default 120 elapsed). State snapshot: `{ outcome, tick, player={x,y,angle}, monster={x,y,state}, extraction={active,discovered,time_remaining} }`.

- [x] Task F — `test/run_test.lua` (new) — Write a busted test file. Depends on Task E (Simulation). Cover at minimum: (1) monster kills player when teleported within 48 px — use `run_until` with a run_config that has no traits, manually set `sim.monster.x/y` to be near the player's pixel position before stepping; (2) extraction outcome — place player at extraction coords in grid units and call `extraction:try_start` then step 61 s; (3) smell trait — verify monster transitions to "alerted" within 3 s of sim time when has_smell is true. Use a `make_config(overrides)` helper at the top to build minimal RunConfig tables.
