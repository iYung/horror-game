## wip-3d Ports Checklist

- [x] Task A — `scripts/generate_sprites.py` + `assets/sprites/` — Write a Python script (using Pillow) that generates solid-colour RGBA PNGs for all billboard types, then run it to populate `assets/sprites/`. Sizes: monster `64×128`, items `64×64`, extraction `32×256`, torch `32×32`. Colours per the design doc table. Output path for each file is `assets/sprites/<name>.png`.

- [x] Task B — `core/lua/scene_manager.lua` — Add fade-in/fade-out transitions. New fields: `_prev`, `_fade_state` ("idle"/"out"/"in"), `_fade_alpha`. On `switch()` when a scene is already active: save current as `_prev`, call `on_enter()` on the new scene immediately, set state to "out". Fade-out draws `_prev` and overlays a black rect increasing to alpha=1, then calls `on_exit()` on `_prev` and switches to "in". Fade-in draws `self.current` and overlays decreasing alpha back to 0. Duration constant `FADE_DURATION = 0.3` seconds. Screen size hardcoded `1280 × 720`. First `switch()` (no previous scene) skips the fade entirely.

- [x] Task C — `core/lua/raycaster.lua` — Extract sprite rendering into a new `Raycaster:draw_sprites(sprites, px, py, angle, lights)` method. Remove sprite handling from `Raycaster:draw()` (walls-only after this change; `opts.sprites` field ignored). The new method accepts sprites with fields `image` (Love2D Image), `scale` (default 1.0), `voffset` (world-unit vertical offset, default 0), `flip_x` (bool, default false), `setup` (fn, optional), `teardown` (fn, optional). Sorting, projection maths, and z-buffer occlusion follow wip-3d's `draw_sprites()` implementation. Fog brightness: for each sprite compute point-light brightness from the `lights` arg (same formula currently used inline) and call `love.graphics.setColor(b, b, b, 1)` before drawing the image. Use scissored image-draw runs (not per-column lines). Rename `self._zbuf` → `self.z_buffer` for consistency.

- [x] Task D — `game/scenes/run_scene.lua` — Update `build_sprites()` to load images from `assets/sprites/` (lazy, cached in a module-level table keyed by filename) and pass `image =` instead of `color =`. Rename `size` → `scale` in all sprite entries. Add `voffset` where appropriate (extraction zone: `voffset = 0.5` to float it slightly). Split `RunScene:draw()` so it calls `self.raycaster:draw(...)` for walls (drop `sprites` from opts) then `self.raycaster:draw_sprites(build_sprites(self), ...)` separately, passing the same `lights` table to both. Pass `self._shake_angle` offset to both calls.
