## Audio System Checklist

Tasks C–G all depend on Task A existing. Task B is independent. Once Task A is done, Tasks C–G can run in parallel (each touches a different file).

- [x] Task A — `game/sound.lua` — Create new file. Sound singleton (module-level, no `new()`). Every function must guard with `if not love.audio then return end` and return early (headless mode has no audio). SFX events (static sources, cloned on each play, loaded only if `love.filesystem.getInfo` finds the file): `"monster_step"`, `"monster_alerted"`, `"item_pickup"`, `"item_use"`, `"extraction_start"`, `"extraction_ready"`, `"player_death"`, `"win"`, `"lose"`. Music tracks (streaming, looping): `"menu"` (`assets/music/menu.*`), `"ambient"` (`assets/music/ambient.*`), `"chase"` (`assets/music/chase.*`). `Sound.update(dt)` advances fade ramps each frame. API: `Sound.load()`, `Sound.update(dt)`, `Sound.play(name)`, `Sound.set_sfx_volume(0..1)`, `Sound.set_music_volume(0..1)`, `Sound.play_music(name)`, `Sound.fade_music(name, target_vol, secs)`, `Sound.stop_music(name)`, `Sound.is_music_playing(name) → bool`. File paths: `assets/sounds/<name>.wav` for SFX, `assets/music/<name>.wav` or `.mp3` for music (try both extensions). Missing files are silently skipped.
